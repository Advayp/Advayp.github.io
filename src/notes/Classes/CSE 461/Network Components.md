- Hosts have various application that are connected to a network, which itself contains routers and links between them
- Applications use networks, hosts support apps, routers relay messages between links, links/channels connect nodes

## Types of Links
- Full-duplex
	- Send data in both directions at the same time
- Half-duplex
	- Send data in both directions, but only one at a time
- Simplex
	- Unidirectional
- wireless links broadcast messages

## Networks by Scale
- Personal Area Network: Vicinity
- Local Area Network: Building
- Metropolitan Area Network: City
- Wide Area Network: Country
- Internet: Planet

## Protocols and Layers
- Each instance of a protocol talks to another instance of that protocol, using that protocol
- Each protocol uses only the services of the lower layer
